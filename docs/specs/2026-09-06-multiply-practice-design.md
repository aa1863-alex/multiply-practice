# 九九乘法表練習網頁 — 設計規格

日期：2026-09-06（2026-09-06 追加調整：方格尺寸、作答秒數限制、放大作答文字、第二輪起題數改為錯題數的兩倍）
專案資料夾：`/Users/klscratch1/multiply-practice`

## 背景與目的

給學生（平板上使用）練習九九乘法表的網頁。可以指定要練習哪些倍數（例如 2 的倍數、7 的倍數），一次出一題，答錯的題目會排入下一輪重考，直到全部答對為止。全程用點選作答，不需要鍵盤。

## 技術架構

- 純 HTML + CSS + JavaScript 單頁應用（無 React/Vue、無建置工具、無框架依賴）。
- 所有邏輯在瀏覽器端執行，無後端、無資料庫、無 API。
- 使用 `localStorage` 記住學生上次的設定（選了哪些倍數、題數、作答模式），下次打開網頁自動帶入。
- 檔案結構：
  ```

  ├── index.html
  ├── style.css
  ├── app.js
  ├── docs/specs/2026-09-06-multiply-practice-design.md
  ├── .gitignore
  └── README.md
  ```

## 畫面一：設定畫面

- **倍數選擇**：顯示 1~9 的數字按鈕（長方形小方格，只比數字本身稍大），可**多選**（例如同時選 2 和 7）。選了哪些數字，之後出題就只從「該數字 × 1~9」的組合中抽題（例如選 2 → 只會出現 2×1 ~ 2×9，不會出現 1×2、3×2 這種反過來的形式）。
- **題數設定**：一個數字輸入框，預設 10，可自行調整。
- **作答模式切換**：兩個選項按鈕—
  - 「數字鍵盤」：作答時顯示 0~9 大按鈕 + 清除 + 確認，讓學生逐位點出答案（支援 1~81 兩位數答案）。
  - 「四選一」：作答時顯示 4 個數字按鈕（1 個正確答案 + 3 個干擾選項，隨機排列）。
- **作答秒數限制**：一個核取方塊「限制每次作答的秒數」，預設**不勾選**（不限秒數）；勾選後旁邊的秒數輸入框才能編輯（預設 10 秒，可自行調整）。
- 「開始練習」按鈕：至少選 1 個倍數才能開始，否則按鈕停用並提示。
- 進入練習畫面前，將這次設定（倍數清單、題數、作答模式）存入 `localStorage`。

## 畫面二：練習畫面

- **一次只顯示一題**，題目文字用大字級顯示（用 `clamp()` 依視窗寬度縮放字體，確保在平板上非常大、清楚易讀），格式如「2 × 7 = ?」。
- 畫面上方顯示目前進度，例如「第 3 題 / 10 題（第 1 輪）」。
- 若設定了秒數限制，題目下方顯示倒數「剩餘時間：X 秒」，剩餘 ≤3 秒時變紅色提醒。
- **作答互動**（依設定選擇其中一種模式呈現）：
  - 數字鍵盤模式：點選數字組成答案顯示在暫存區（字級加大、顏色為淡藍色，與題目文字的深色區隔），可點清除重來，點確認送出；數字鍵盤按鈕本身字級也加大。
  - 四選一模式：點選其中一個選項即視為送出答案；四個選項數字字級大幅加大。
- **作答回饋**：
  - 送出答案後立即用顏色標示對（綠）或錯（紅）。
  - 若第一次答錯（或秒數限制下第一次逾時未作答）：允許**立刻重新作答一次**（同一題），秒數限制開啟時會為這次重試重新倒數。
  - 若第二次仍答錯或逾時：顯示正確答案，然後才進入下一題。
  - **判定規則**：只要這一題不是「第一次就答對」，無論後面有沒有補答對，這一題都算「錯」，會被排入下一輪重考清單。
- 全部按鈕皆為大尺寸觸控目標，不出現任何文字輸入框或呼叫系統鍵盤。

## 重考邏輯（跨輪次）

- 第 1 輪：從選定倍數的題目池中隨機抽出設定的題數（預設 10 題）。
- 每一輪結束後：
  - 若這一輪沒有任何錯題 → 視為練習完成，進入完成畫面。
  - 若有錯題 → 建立下一輪題目：**題數為錯題數的兩倍**——全部錯題 + 等量（與錯題數相同的數量）從**這一輪答對的題目**中隨機抽取的題目補滿（例如錯 1 題 → 下一輪 2 題；錯 2 題 → 下一輪 4 題）。若這一輪全部答錯（沒有答對過的題目可抽），則改從整個題目池中隨機抽取來補滿。
- 重複上述流程，直到某一輪「全對」為止。
- 此規則從第 2 輪起生效，且往後每一輪都套用同樣的「錯題數 × 2」規則，題數會隨錯題狀況動態增減，不再固定等於設定的題數。

## 畫面三：完成畫面

- 顯示恭喜訊息。
- 顯示統計：總共花了幾輪、總作答次數、整體正確率（第一次就答對的題數 / 總作答題數次數）。
- 「再練習一次」按鈕：回到設定畫面（沿用上次設定或允許重新選擇）。

## 資料模型（JS 內部）

```js

// 練習狀態
{
  settings: { multipliers: [2, 7], questionCount: 10, mode: 'keypad' | 'choice' },
  round: 1,
  currentQueue: [...題目...],   // 這一輪剩餘題目
  wrongThisRound: [...題目...], // 這一輪答錯（含補答對也算錯）的題目
  correctThisRound: [...題目...],
  stats: { totalAttempts, totalFirstTryCorrect }
}
```

## 部署流程

1. 在 `/Users/klscratch1/multiply-practice` 建立 git repo 並 commit 程式碼。
2. 建立 GitHub repo `multiply-practice`（public 或 private 由使用者當下決定）並 push。
3. 使用者自行到 Cloudflare Dashboard 連接該 GitHub repo，建立 Cloudflare Pages 專案，並自訂網域/專案名稱（Cloudflare 端設定不由 Claude 代為操作）。
4. 之後每次 `git push` 到 GitHub，Cloudflare Pages 會自動重新部署（GitHub 整合式自動部署，非本使用者一般偏好的 wrangler CLI 手動部署方式，此專案為例外，使用者已明確要求）。

## 不在範圍內（YAGNI）

- 不做使用者帳號、不做多人/雲端進度同步。
- 不做除了 ×（乘法）以外的運算（無加減除）。
- 不做音效、動畫特效等額外裝飾。
- 不支援反向題目形式（N × 選定數字）。
